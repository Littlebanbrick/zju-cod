# Lab 4 测试程序汇编源

本目录保存原始实验材料中的汇编程序源文件，便于和 `program/*.mem` 中的机器码对照。

| 汇编源 | 机器码 | 对应阶段 | 说明 |
| --- | --- | --- | --- |
| `I_mem_4.S` | `program/I_mem_4.mem` | Lab4-2 | 基础指令与整条单周期数据通路测试；原始材料中也用于 Lab4-1 集成/上板观察 |
| `I_more.S` | `program/I_mem_more.mem` | Lab4-3 | 26 条指令扩展测试，原始文件名即 `I_more.S` |
| `I_more_INT.S` | `program/I_mem_INT.mem` | Lab4-4 | 非法指令、`ecall`、外部中断和 `mret` 返回测试 |

原始材料中还存在 `test.S`、`I_mem_4.S`、多个 `I_more.S` 副本以及 `I_more_INT_pc.S` 等变体，内容基本相同，区别主要是注释、文件名和少量调试说明。本目录每个测试保留一份与当前 `.mem` 对应的规范源文件，避免重复副本造成混淆。

仿真直接使用 `program/*.mem`；汇编源用于阅读、修改和重新生成机器码。重新生成后请保持原有指令地址和 PC 检查点不变。
